# 📊 Superstore Sales Analysis | End-to-End Data Analytics Project

## 📌 Project Overview

This project is an end-to-end Data Analytics solution built using the Superstore Sales dataset. It demonstrates the complete analytics workflow, starting from raw data processing to interactive dashboard creation and business insights.

The objective is to analyze sales performance, customer behavior, product performance, profitability, shipping trends, and forecast future sales using industry-standard analytics tools.

---

## 🎯 Project Objectives

- Clean and preprocess raw sales data.
- Perform Exploratory Data Analysis (EDA).
- Analyze business data using SQL.
- Develop an interactive Power BI dashboard.
- Generate actionable business insights.
- Forecast future sales trends.

# 💡 Key Business Insights

- Consumer segment generated the highest sales.
- Office Supplies was the highest-selling product category.
- Standard Class shipping mode was used most frequently.
- California generated the highest overall sales.
- Cash on Delivery (COD) was the most preferred payment method.
- Sales increased significantly during the final quarter of the year.
